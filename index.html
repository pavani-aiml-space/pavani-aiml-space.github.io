Slack to Jira Triage Agent

Python

Watches a Slack channel, classifies each message with an LLM, and files a structured Jira ticket, escalating to a human instead of guessing when confidence is low. Duplicate detection by embedding similarity, plus a golden-dataset eval harness with LLM-as-judge scoring.

Incident Overdue Alert Agent

TypeScript Live page

Watches a Jira project for incidents that have gone stale past a threshold, surfaces them on a live Next.js dashboard, and emails each owner a digest carrying a due date, an action plan, and a documented reason for anything still unaddressed.

Reusable QA Framework

TypeScript Live page

A Playwright test framework you set up once and point at any application. Each app supplies only its own URL, login, and test data, and the shared rules never change. An AI can propose a test, but nothing counts as governed coverage until a person approves the plan.

NLQ-SQL

Python Live page

Turns a plain-English question into SQL against a Postgres database, validates it against a safety policy, and feeds errors back to the model to self-correct. Includes an automatic multi-step query planner, a correctness-and-injection benchmark suite, and an MCP server.

Instagram Content Agent

Python

A multi-agent pipeline that takes a topic, writes the caption, generates the image, and publishes to Instagram. Each agent calls a real MCP server over stdio rather than an in-process function, chained with LangChain LCEL behind a FastAPI backend.
