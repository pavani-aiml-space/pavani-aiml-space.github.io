Product

Echoes of Home

In App Store review
  • Started as a personal project: preserve my grandmother's recipes and my dad's poems in their own words, as a keepsake for my family.
  • Wrote PRDs and a phased roadmap before writing code (docs/plans), and defined test cases and expected behavior before building each feature (TDD), enforced with custom spec-driven-development skills as structural guardrails while building with AI coding agents.
  • Built as a 3-stage AI pipeline (transcribe with Whisper, translate/structure with Gemini, persist), with translation and structuring kept as two separate LLM calls, so translation doesn't flatten grandma's phrasing like "a handful" into an exact measurement.
  • FastAPI + Next.js on Supabase (Postgres, Auth, Storage), with JWT auth, rate limiting, and content moderation before anything is saved.
  • Recording flow: record narration in Telugu, transcribe, review and correct the transcript, then save as a structured memory alongside the original audio.
  • Packaged the web app into a native iOS app using Capacitor, which wraps an existing web codebase for app stores instead of rebuilding natively, so no separate iOS-specific codebase was needed.

Slack to Jira Triage Agent

Python

Watches a Slack channel, classifies each message with an LLM, and files a structured Jira ticket, escalating to a human instead of guessing when confidence is low. Duplicate detection caught a real duplicate at 97.43% embedding similarity; on-demand memory retrieval keeps ~80% of blocks token-free. 341 tests, golden-dataset eval harness with LLM-as-judge scoring.

Incident Overdue Alert Agent

TypeScript

Watches a Jira project for incidents that have gone stale past a threshold, surfaces them on a live Next.js dashboard, and emails each owner a digest with a due date, an action plan, and a documented reason for anything still unaddressed. An AI read flags what the priority label alone misses: a real example caught a Medium-priority ticket masking a silent data-integrity bug, 64 days open.

Reusable QA Framework

TypeScript

A Playwright test framework you set up once and point at any application. Each app supplies only its own URL, login, and test data, and the shared rules never change. An AI can propose a test, but nothing counts as governed coverage until a person approves the plan. Validated against this portfolio's own production app (Echoes of Home) plus 4 legacy-code scenarios: 21 of 22 requirements demonstrated with real evidence, including 2 real defects found, classified, and fixed.

NLQ-SQL

Python

Turns a plain-English question into SQL against a Postgres database, validates it against a safety policy, and feeds errors back to the model to self-correct: a real recorded run caught a wrong column name, retried, and produced the right query. Includes an automatic multi-step query planner, a 16-case correctness plus 3-case adversarial-injection benchmark suite, and an MCP server.
