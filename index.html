Echoes of Home

In App Store review
  • Started as a personal project, a keepsake for family: my grandmother's recipes and my dad's poetry, in their own words, then built out into something other families could use too.
  • A 3-stage AI pipeline (transcribe with Whisper, translate/structure with Gemini, persist) on FastAPI + Next.js/Supabase, built with PRDs and test cases written before each feature, enforced by custom spec-driven-development skills.
  • Record narration in Telugu, review and correct the transcript, then save as a structured memory, packaged into a native iOS app via Capacitor so no separate iOS codebase was needed.

Slack to Jira Triage Agent

Python
  • Watches a Slack channel, classifies each message with an LLM, and files a structured Jira ticket, escalating to a human instead of guessing when confidence is low.
  • Duplicate detection by embedding similarity, and on-demand memory retrieval that only pulls in past context when the model is genuinely uncertain.
  • Golden-dataset eval harness with LLM-as-judge scoring.

Incident Overdue Alert Agent

TypeScript
  • Watches a Jira project for incidents that have gone stale past a threshold, surfaces them on a live Next.js dashboard.
  • Emails each owner a digest with a due date, an action plan, and a documented reason for anything still unaddressed.
  • A single LLM call per digest reads each overdue ticket's actual description text, not just its priority label, to flag risk the label alone would hide, a real example caught a Medium-priority ticket masking a silent data-integrity bug.

Reusable QA Framework

TypeScript
  • A Playwright test framework you set up once and point at any application, each app supplies only its own URL, login, and test data, and the shared rules never change.
  • An AI can propose a test, but nothing counts as governed coverage until a person approves the plan.
  • Validated against this portfolio's own production app (Echoes of Home) plus several legacy-code scenarios, with real defects found, classified, and fixed along the way.

Continuum

Python
  • A governed RAG pipeline: retrieval searches across a scattered data estate, but answering is structurally restricted to only what's been explicitly reviewed and approved.
  • That restriction is enforced at the retrieval layer itself, not just requested of the model.
  • Hybrid dense+sparse retrieval with RRF fusion (searches both by meaning and by keyword, then re-ranks everything by how well it did across both), citations that resolve back to source text, and confidence-gated guardrails.

NLQ-SQL

Python
  • Turns a plain-English question into SQL against a Postgres database, validates it against a safety policy, and feeds errors back to the model to self-correct.
  • A real recorded run caught a wrong column name, retried, and produced the right query.
  • Includes an automatic multi-step query planner, a correctness and adversarial-injection benchmark suite, and an MCP server.

Instagram Content Agent

Python
  • A multi-agent pipeline that takes a topic, writes the caption, generates the image, and publishes to Instagram.
  • Each agent calls a real MCP server over stdio rather than an in-process function.
  • Chained with LangChain LCEL (pipes each step's output straight into the next, with built-in retry on failure) behind a FastAPI backend.
